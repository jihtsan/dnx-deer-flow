# 领域文档

本仓库使用 single-context 领域文档布局：前端、后端和跨模块功能共享同一套领域术语与架构决策。

## 开始工作前

- 阅读仓库根目录的 `CONTEXT.md`，使用其中定义的领域术语。
- 阅读 `docs/adr/` 中与当前工作相关的 ADR。
- 如果文件不存在则继续工作，不应仅为补齐目录而创建空文档。

## 使用规则

- 前端和后端必须使用同一个领域概念名称，避免自行创造同义词。
- 新概念只有在真实需求中被明确后才加入 `CONTEXT.md`。
- 如果实现方案与已接受 ADR 冲突，必须明确指出并重新评估，不能静默覆盖。
- 只有真正影响整个仓库的稳定决策才进入根目录 ADR。
