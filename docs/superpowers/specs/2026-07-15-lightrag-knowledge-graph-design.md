# LightRAG 知识图谱展示需求

**Date**: 2026-07-15
**Status**: Approved for implementation
**Surface**: `/workspace/knowledge` -> `知识图谱`

## 目标

在知识库工作台中展示当前 LightRAG workspace 已索引文档形成的全局知识图谱，使用户可以浏览实体类别、定位指定实体、理解实体关系，并追溯实体与关系的来源文档。

图谱默认展示全局数据，不要求用户预先选择中心实体。类别、搜索结果和节点选择都是全局图谱上的聚焦入口，不创建另一份图谱数据。

## 范围

本期图谱只展示 LightRAG 提供的以下内容：

- 实体及其 `entity_type`、描述和来源文档。
- 实体之间的关系、关系描述、关键词、权重和来源文档。
- 当前 LightRAG workspace 中互不连通的图谱分量。

## 明确不包含

- 光伏、储能、充电桩等场站设备的实时运行拓扑。
- 实时遥测、告警、调度状态或数字孪生数据。
- 通过知识图谱直接执行场站控制。
- 由前端虚构的实体、关系、分类或演示数据。
- 要求用户从大量实体中选择“中心实体”后才能查看图谱。
- 在图谱上方展示热门实体 Top 20 快捷入口。
- 从图谱来源跳转到知识库文档详情或文档预览。
- 一期移动端布局和触摸手势适配；一期只对桌面端交互负责。

## 领域语言

### 实体类别

LightRAG 为实体返回的 `entity_type`。实体类别用于聚合和筛选语义相同的实体，不等同于社区、聚类或具体实体。

### 全局图谱

当前 LightRAG workspace 中跨文档、跨连通分量的实体和关系集合。全局图谱最多展示 5,000 个逻辑节点；达到接口限制时必须明确提示数据已截断。

## 信息结构

图谱工作区按以下顺序组织：

1. 图谱摘要：节点数、关系数、数据状态和截断状态。
2. 实体类别 Top 20。
3. 实体搜索。
4. 全局 Canvas 图谱。
5. 选中实体详情和边关系信息浮层。

图谱上方只显示一行“实体类别 Top 20”，不得把当前热门实体接口结果混入该行或称为“分组”。

## 已确认交互

### 默认状态

- 页面进入后直接加载全局图谱。
- 不显示中心实体选择器。
- 未选择类别或实体时展示全部已加载节点和关系。

### 实体类别 Top 20

- 类别统计只基于接口返回的当前已加载图谱节点，不额外执行全 workspace 聚合。
- LightRAG 返回空白或缺失的 `entity_type` 时，统一归入中性色的“未分类”；“未分类”正常参与数量统计和 Top 20 排名。
- 按每个类别包含的已加载实体数量降序排列，展示当前图谱中的前 20 个实体类别。
- 类别入口同时显示类别名称和实体数量，例如 `ORGANIZATION 128`。
- Top 20 类别基于 LightRAG 原始 `entity_type` 使用稳定颜色映射，同一类别在数据未变化时保持同色。
- Top 20 之外的实体归入中性色的“其他”显示类别，但保留各节点原始 `entity_type` 供详情展示。
- 点击类别后，属于该类别的节点突出显示。
- 其他类别节点保留在原位置并降低视觉权重，不从图谱中删除。
- 跨类别关系仍然可见，避免类别聚焦造成关系链断裂。
- 用户可以恢复“全部类别”状态。
- 类别选择状态必须同时使用文字、数量、描边和透明度表达，不得只依赖颜色。
- 当全局图谱被截断时，类别区域明确提示“基于已加载的 {node_count} 个节点统计”，不得把类别数量描述为整个 LightRAG workspace 的完整统计。

### 实体搜索

- 一期搜索范围限定为当前已加载图谱，不搜索或动态加载未包含在当前图谱响应中的 workspace 实体。
- 用户可以按实体名称搜索当前已加载的 LightRAG 图谱实体。
- 选择搜索结果后，画布应将对应节点移动到可见区域。
- 搜索不得替换或重新定义全局图谱数据集。
- 当全局图谱被截断时，搜索区域提示“仅搜索已加载节点”。
- 搜索选择的优先级高于实体类别聚焦：选择搜索结果时清除当前类别聚焦，定位实体、突出一跳边关系并打开实体详情。
- 关闭搜索实体详情后保持“全部类别”状态，不自动恢复此前的类别聚焦。

### 节点详情

当前 LightRAG 图谱接口能够可靠提供并允许详情展示：

- 实体名称。
- LightRAG 原始实体类别 `entity_type`。
- 实体描述；上游未提供时显示明确的空状态，不生成摘要。
- 安全化后的来源文件名；一期只展示文本，不提供跳转或预览入口。
- 当前已加载图谱中的直接关联实体数量。该数值必须标为“当前图谱关联数”，因为全局图谱截断时它不代表完整 LightRAG 关联总数。

实体详情不包含关联实体排序或完整关系列表。关系信息属于画布上的边关系，避免在实体详情中重复表达同一结构。

### 边关系

- 用户点击实体后，画布突出该实体的一跳边关系及直接关联实体。
- 每条边关系保留明确方向，并可展示关系类型或关键词、关系描述、关系权重和来源文件名。
- 关系权重直接来自 LightRAG，界面必须标注为“关系权重”，不得描述为置信度、概率或准确率。
- 全局状态不常驻显示全部边标签，避免大量连线文本相互遮挡。
- 点击实体后，只在该实体的一跳高亮边上显示“关系类型或关键词 + 关系权重”。
- 悬停或点击高亮边时，通过紧凑浮层展示关系描述和来源文件名。
- 不支持悬停的设备必须能够通过点击边获得相同信息。

当前接口不能可靠提供以下内容，因此本期不得伪造：

- 实体对应的原文片段或页码。
- 实体识别置信度。
- 实体创建或更新时间。
- 可直接跳转的知识库文档 ID。
- 一个实体跨多个来源文档的结构化来源列表。

一期不为图谱来源补充文档 ID 映射。来源文件名不得渲染为暗示可以跳转的链接或按钮。

## 展示与性能约束

- 一期目标视口为宽度不小于 1024px 的桌面端。
- 使用 Canvas 绘制图谱，不为每个节点创建 DOM 元素。
- 支持最多 5,000 个逻辑节点。
- 平移、缩放或图谱重绘不能触发逐节点 React 渲染。
- 标签密度随缩放级别变化，避免所有标签同时显示。
- 保留小型和不连通的文档图谱分量，不能只展示最大连通分量。
- 页面必须显式展示接口返回的截断状态，不能把“未加载”误解为“没有数据”。

## 数据刷新

- 首次进入知识图谱页签时加载图谱。
- 再次进入页签时检查缓存状态，并在图谱已过期时重新加载。
- 页面提供明确的手动刷新按钮。
- 查看图谱期间不执行定时轮询，也不因浏览器窗口重新获得焦点而自动刷新和重排画布。
- 文档索引完成或删除成功后，将图谱数据标记为已过期；下次进入图谱页签或用户手动刷新时获取新数据。

## 后续移动端方向

以下内容不属于一期验收范围，仅记录后续适配方向：

- 实体类别 Top 20 横向滚动。
- 保留实体搜索。
- Canvas 支持单指平移、双指缩放和点击节点。
- 节点详情改为画布下方的面板，避免遮挡主要图谱。
- 边详情通过点击触发，不依赖悬停。
- 减少可见标签密度，但不减少实际节点数据。

## 当前实现差距

- 当前前端把 LightRAG 的 `entity_type` 通过规则压缩为人物、组织、地点、产品、技术和概念六种显示类型，没有直接展示实际实体类别 Top 20。
- 当前顶部 20 项来自热门实体接口；目标实现应将它替换为按实体数量排序的“实体类别 Top 20”。
- 当前节点详情使用归并后的显示类别并包含简化关系列表；目标结构应展示 LightRAG 原始类别，把关系描述、权重和关系来源归属到画布边关系，只在侧栏展示被点击实体本身的信息。
- 当前搜索调用全 workspace 标签搜索接口，可能返回不在已加载图谱中的实体；目标实现应只提供能够在当前 Canvas 中定位的结果。

## 验收标准

- LightRAG 返回多个 `entity_type` 时，页面可以展示类别入口并准确关联对应节点。
- 实体类别按实体数量降序排列；同一输入产生稳定顺序，并且每个类别显示准确的实体数量。
- 空白或缺失的 `entity_type` 归入“未分类”，使用中性色并参与 Top 20 排名。
- 类别数量与当前已加载图谱节点一致；图谱截断时显示基于已加载节点的统计口径。
- 同一原始实体类别获得稳定颜色；Top 20 之外统一使用“其他”中性色，节点详情仍显示真实原始类别。
- 点击一个类别后，该类别节点突出，其他节点弱化但仍存在，跨类别关系保持可见。
- 类别选择状态不依赖颜色即可辨认。
- 图谱上方只存在“实体类别 Top 20”入口，不显示热门实体快捷入口。
- 来源文件名以只读文本展示，不提供文档详情或预览跳转。
- 点击实体后，详情只展示该实体信息；一跳关系路径在画布上突出显示。
- 全局状态不常驻显示全部边标签；选择实体后，一跳高亮边展示关系类型或关键词及 LightRAG 关系权重。
- 悬停或点击高亮边可以查看关系描述和来源文件名，并避免使用置信度含义的文案。
- 搜索结果全部来自当前已加载图谱，可以定位真实节点并打开其详情；图谱截断时显示搜索范围提示。
- 搜索选择会清除类别聚焦；搜索实体及其一跳关系不会因先前类别状态而被弱化。
- 全局图谱包含来自不同文档的连通分量。
- 5,000 节点输入不会生成逐节点 DOM，也不会因交互导致画布容器尺寸跳动。
- LightRAG 离线、返回空图或返回截断图时，页面分别展示真实且可区分的状态。
- 查看图谱期间不会因轮询或窗口聚焦触发意外重排；图谱过期后可在重新进入页签或手动刷新时更新。

## Obsidian 参照边界

本需求借鉴 Obsidian 图谱在渲染与负载控制上的原则，而不照搬其信息架构：

- 使用 Canvas 类渲染面承载大量节点，避免逐节点 DOM。
- 通过视口裁剪、缩放级标签密度和按需重绘控制绘制负载。
- 将全局总览与局部聚焦分开；本期保持全局数据集，节点点击只形成临时的一跳聚焦。
- 搜索和类别是可见性控制，不是重新生成图谱的入口。
- 不把通用力导向图直接当作业务分类体系；实体类别始终以 LightRAG 原始 `entity_type` 为准。

具体实现证据与限制见 [`docs/research/obsidian-graph-rendering.md`](../../research/obsidian-graph-rendering.md)。
